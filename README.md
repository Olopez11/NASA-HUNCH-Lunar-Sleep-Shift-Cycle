# NASA-HUNCH-Lunar-Sleep-Shift-Cycle
Team Shifter for the NASA HUNCH Project, School Year 2026-2027 
This is done for a School / Nasa Project during Our Senior Year. 
It is dedicated to helping astronauts adapt to any changes in their sleep by planning the days before the event occurs, as well as
provides suggestions such as naps, melatonin, and other medications that may be useful to them depending on their circumstances. 
This is made all through C++ using Microsoft tools such as CMake to give it its visual look and GUI. Without it, we would simply be looking at code, 
Our goal is to use calculations from trusted sources to calculate a fatigue score, as well as save any changes made to the schedule for anyone to see, and keep records of them
